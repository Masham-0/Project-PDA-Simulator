# Pushdown Automata (PDA) Simulator

A modern **web-based Pushdown Automata Simulator** built using **HTML, CSS, and JavaScript** for the subject **CMCSC401 – Theory of Automata and Formal Languages**.

This project provides an **interactive and visually rich environment** to simulate how a **Pushdown Automaton (PDA)** works internally using:
- state transitions
- stack push and pop operations
- epsilon transitions
- step-by-step execution
- real-time execution trace
- animated stack visualization

It is designed as an **academic project submission** as well as an educational visualization tool.

## 📚 What is a PDA?

A **Pushdown Automaton (PDA)** is an extension of a **Finite Automaton (FA)** with an additional **stack memory**.

The stack allows the automaton to:
- remember previously seen symbols
- recognize **context-free languages**
- validate nested structures
- parse recursive grammar rules

A PDA is widely used in:
- compiler design
- syntax parsing
- balanced parentheses validation
- XML / HTML tag checking
- expression evaluation
