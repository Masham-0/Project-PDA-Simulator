Input & Transition Rules

Input String

Enter symbols without spaces (e.g., aabb). Use e for an empty string input.

Transitions

Format: CurrentState, Input, StackTop -> NextState, PushString

  • e: Represents Epsilon (empty move).
  • PushString: Characters to push onto the stack.
  • e (in PushString): Pops the stack without adding new symbols.
